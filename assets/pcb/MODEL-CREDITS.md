# KiCad package models

Converted from the official KiCad packages3D VRML library to Three.js JSON on 2026-10-30. Geometry is unchanged; runtime converts VRML units to millimeters and aligns it to the board plane. Original VRML sources with author and license headers are included in model-sources/. These are library packages, not Mahir’s raw board/schematic files.

Most packages use CC-BY-SA 4.0 with the KiCad electronic-design exception. DIP-28 uses GPL-3.0-or-later with the exception preserved in its source header. Consult each source header for exact attribution and terms.
